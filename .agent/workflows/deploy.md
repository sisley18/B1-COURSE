# B1 Course Deployment Workflow

When making changes to the B1 COURSE project:

1. After making any code changes, automatically commit and push to GitHub
2. Use descriptive commit messages summarizing the changes
3. Push to origin main branch

## Commands to run after changes:
// turbo
```
git add -A
```
// turbo
```
git commit -m "[descriptive message]"
```
// turbo
```
git push origin main
```

This ensures students always get the latest version when they refresh the page at:
https://stmaryslanguagecourse.netlify.app
